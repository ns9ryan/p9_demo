# P9 总网分站管理页面清单

> 用途：用于梳理总网侧分站管理需要开发的主要页面，后续可以按页面逐个补齐 API / RPC。
>
> 本清单只统计主要页面和创建分站步骤页，新增、编辑、调整、发布确认、重置密码等弹窗不单独统计。

## 一、页面数量概览

| 分类 | 页面数量 |
|---|---:|
| 分站主体管理 | 7 |
| 域名管理 | 1 |
| 管理员账号管理 | 1 |
| 语言分配 | 1 |
| 经营地区分配 | 1 |
| 代理子线路分配 | 1 |
| 游戏资源分配 | 1 |
| **合计** | **约 13 个页面** |

---

# 二、分站主体管理

共约 **7 个页面**。

## 1. 分站列表

主要功能：

- 查询分站列表
- 按分站名称、编码、状态、发布状态等筛选
- 创建分站
- 查看详情
- 编辑分站
- 发布分站

后续主要接口能力：

- 分站列表查询
- 分站详情查询
- 分站状态相关操作
- 分站发布

---

## 2. 分站详情

用于集中查看一个分站的完整信息。

主要展示：

- 基础信息
- 档案信息
- 管理员账号
- 域名
- 语言
- 经营地区
- 代理子线路
- 游戏资源
- 分站状态
- 发布状态

后续主要接口能力：

- 查询分站完整详情
- 查询分站关联的各类资源

---

## 3. 创建分站 - 第 1 步：基础信息

主要内容：

- 分站名称
- 时区
- 币种
- 状态
- 备注

主要操作：

- 保存草稿
- 下一步

后续主要接口能力：

- 创建分站草稿
- 保存 / 修改基础信息

---

## 4. 创建分站 - 第 2 步：档案信息

主要内容：

- 公司名称
- 主要联系人
- 联系方式
- 客服联系方式
- 总网对接后台管理源 ID
- 总网内部档案备注

主要操作：

- 上一步
- 保存草稿
- 下一步

后续主要接口能力：

- 查询档案信息
- 保存 / 修改档案信息

---

## 5. 创建分站 - 第 3 步：管理员与域名

主要内容：

- 初始管理员账号
- 初始密码
- 分站后台域名
- 代理后台域名
- H5 域名

主要操作：

- 上一步
- 保存草稿
- 下一步

后续主要接口能力：

- 创建初始管理员
- 配置初始域名
- 保存当前创建进度

---

## 6. 创建分站 - 第 4 步：资源分配

主要内容：

- 语言
- 经营地区
- 代理子线路
- 游戏资源

主要操作：

- 勾选初始资源
- 上一步
- 保存草稿
- 下一步

后续主要接口能力：

- 查询可分配资源
- 保存语言分配
- 保存经营地区分配
- 保存代理子线路分配
- 保存游戏资源分配

---

## 7. 创建分站 - 第 5 步：确认创建

主要内容：

- 汇总前面各步骤的信息
- 检查当前配置
- 返回指定步骤修改
- 完成创建

主要操作：

- 上一步
- 保存草稿
- 完成创建

完成创建后：

```text
创建完成
→ 分站处于未发布状态
→ 返回分站列表
→ 人工确认
→ 点击发布
```

后续主要接口能力：

- 查询创建草稿完整信息
- 完成创建
- 校验创建条件

---

# 九、后续接口开发建议顺序

建议后面按照页面依赖顺序补接口：

```text
1. 分站列表
2. 创建分站 - 基础信息
3. 创建分站 - 档案信息
4. 创建分站 - 管理员与域名
5. 创建分站 - 资源分配
6. 创建分站 - 确认创建
7. 分站详情
8. 域名管理
9. 管理员账号管理
10. 语言分配
11. 经营地区分配
12. 代理子线路分配
13. 游戏资源分配
```

其中创建分站流程依赖最多，建议先把分站主体和草稿机制跑通，再逐步接入管理员、域名和各类资源分配。

# 十、当前统计结论

当前总网侧分站管理大约需要：

```text
主要页面 / 步骤页：13 个
```

不单独统计：

- 新增弹窗
- 编辑弹窗
- 调整分配弹窗
- 发布确认弹窗
- 重置密码弹窗
- 启用 / 停用确认弹窗

这些属于对应页面内部的操作。

如果后续把“编辑分站”从弹窗调整成独立页面，则总页面数再增加 1 个。
